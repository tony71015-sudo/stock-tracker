## 計算定義

- **股票分割**：0050 2025-06-18 1 拆 4。股數 ×4，投入本金不變，每股帳面成本約 ÷4；事件發生在當日收盤模擬買入之前。拆股增加股數在投入事件表中列示。
- **投入／加碼**：每筆日期、預算獨立設定；當日非交易日，以下一個可得交易日**收盤價**模擬買入整股。輸入金額不足買一股會留在預算餘額，不計入已投入成本。手續費可自行輸入百分比，預設為 0。
- **純價格報酬**：市值 - 外部實際投入（買入價款及選定手續費），不含配息。
- **股息留現金**：除息日按該日買入前已持有股數確定股息權益；發放日前列為應收股息，發放後列現金。總資產 = 市值 + 應收股息 + 累積股息現金。
- **股息再投入**：發放日後**第一個交易日收盤價**用已收到的股息現金模擬加買整股。再投入股數加入持有部位與帳面成本，但**不增加外部投入本金**。不足買整股的股息現金仍在現金帳戶。
- **含息損益**：股票市值 + 留存股息現金 + 待發股息 - 外部投入本金。報酬率 = 含息損益 / 外部投入本金。
- **最大獲利／最低損益**：按模擬持股、逐日收盤及當日已知股息權益計算，同時列最高／最低報酬率。跨多次加碼的最高金額會受到投入本金變化影響。
- **XIRR**：以實際投入價款作負現金流、最後一個可得收盤日的整體資產價值作正現金流，反映投入日差異；股息視為留在投資組合內，不額外重複當作外部現金流入。短期、單日及無法求根情況顯示資料不足。

## 資料完整性與已知限制

- 價格採 TWSE `STOCK_DAY` 未還原的每日收盤價；**股息及分割由事件引擎分別計算，不使用「已還原價格」重複處理股利**。
- 配息嘗試查詢證交所 `rwd/zh/ETF/etfDiv`，回傳欄位不符、沒有可驗證日期或來源暫時失敗時，不創造假股息，也不覆蓋過往有效檔案；沒有配息檔案時，不提供含息總報酬。
- 官方來源目前標示的歷史起點為 2005 年。0050 的 **2003–2004 年配息可能缺漏**；投資日期早於歷史涵蓋起點時，長期含息結果不可視為完全精確。
- 目前**僅模擬整股**，不含零股成交價格、價差、滑價、賣出交易稅、股息所得稅與所得稅效果，也不保證可在收盤價實際成交。
- 這不是券商對帳系統。所有資料及估算結果須與發行投信、證交所等官方資訊再次核對，**切勿完全相信作為投資決策唯一依據**。
- 本修正版已經進行 Python / JavaScript 語法及模擬交易、分割與配息邏輯測試；**在 GitHub Actions 取得全部真實歷史配息仍須實機驗證**。
