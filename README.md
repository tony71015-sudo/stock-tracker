# 投資風控中心 Trade Compass ｜整合版 v1.2（2026-11-13）

## 本次新增：個股未實現損益與價格更新

- 「總覽儀表板」上方的未實現損益總金額保留。
- 「目前持股」每檔分別顯示 **未實現損益金額、報酬率、估值價格、價格日期、來源**。
- 每檔提供「更新價格」，輸入 **日期與參考價** 即可更新市值與損益，不需要填寫未知的最高／最低價。
- 手動參考價只計算估值，不參與移動停利停損；需另外輸入完整日線高低收行情才能判讀停損警示。
- 手動價格在「資料匯入與備份」可逐筆檢視與刪除錯誤紀錄。
- 每筆參考價依所屬日期保存，總覽查詢過去日期時不會偷用未來價格；跨日買進的平均成本仍依原有交易紀錄計算。
- 右側表格沒有報價的持股會標示「待輸入價格」，該檔不納入已報價市值及總未實現損益。
- 新增「更新與儲存說明」分頁，說明 v1.0 / v1.1 / v1.2 變更與資料儲存／備份／清除流程。
- 進入首頁時若從未點選 JSON 備份，或上次點選已達 30 天，顯示提醒（此為「點選」時間，請自行確認備份檔案確實下載）。

## 原本功能保留

- 跨日期交易成本、總覽、交易紀錄、每日高低收盤行情、移動停利停損、國泰證券 2.8 折損益試算。
- 保留原 localStorage 儲存鍵 `trailing-stop-tw-web-v1`，原有交易及策略設定不會因升級而重新建立。
- JSON 完整備份現新增 `manualPrices` 與 `lastBackupAt`，舊版 JSON 仍可還原；CSV 依舊只提供交易及每日行情兩類。

## 資料在哪裡？

- 網站 HTML/JS 透過 GitHub Pages 公開託管；使用者輸入的交易、手動價格與設定**存放目前裝置的該瀏覽器網站 localStorage**，不會被本站傳至 GitHub。
- 同台電腦改用另一個瀏覽器／使用者設定檔，或換手機／換電腦，**不會自動同步**。請在舊裝置下載 JSON，於新裝置使用「還原 JSON」。
- 關閉分頁、關機通常不會刪除資料。清除網站資料、使用無痕模式或移除瀏覽器設定檔可能造成永久遺失。
- **個人電腦不建議定期清除**；建議每月至少備份一次。使用公用裝置時，確認備份後再清除網站資料。

## 更新到原本 GitHub Pages

1. 在舊網站「資料匯入與備份」下載完整 JSON 並確認檔案。
2. 登入 GitHub `tony71015-sudo/stock-tracker` 專案，將原本根目錄的 `index.html` 用本檔覆蓋並提交（Commit changes）。
3. Github Pages 使用既有 `main / (root)`，不須重新設定。
4. 打開 https://tony71015-sudo.github.io/stock-tracker/ ，檢查交易紀錄、參考價試算與「更新與儲存說明」。
5. 若畫面仍為舊版，請強制重新整理（Ctrl+F5）；不要先清除網站資料。

## 重要限制

- 完全靜態網站，無即時報價、券商 API、雲端同步與自動交易。
- 未實現損益 = 估值價格 × 持股股數 − 持有總成本（買入手續費已列入成本），**未扣未來賣出手續費及交易稅**。
- 需要自行更新日期與報價；僅更新參考價不會重算日線的觸及停利停損警示。
- 股利、除權息、拆併股、減資等特殊事件仍需自行調整。
