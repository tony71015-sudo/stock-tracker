# 移動停利停損｜網頁版

## 使用方式
- 離線使用：直接用 Chrome / Edge 開啟 index.html 即可。
- 上線：將 index.html 放到 GitHub Pages 專案根目錄，網站可透過 HTTPS 存取。
- 在「交易紀錄」輸入多筆買賣，再於「價格追蹤」加入每日最高價／最低價／收盤價。
- 「價格追蹤」會以股票代號與查詢日期，自動計算剩餘股數、每股平均成本、總成本與移動停利警示。
- Excel 舊檔：點選「資料匯入與備份」>「匯入 Excel」，選擇含有「交易明細」和「交易追蹤表」的 .xlsx 檔案。

## 資料保存 / 重要限制
- 瀏覽器 localStorage 只保存在當前裝置及同一網址／檔案位置，換裝置不會同步，請定期下載 JSON 完整備份。
- 無即時行情、無券商 API 串接、無自動下單。
- 買進手續費計入持股成本；部分賣出採平均成本法；賣出費用及交易稅影響已實現損益。
- 全數賣出後重新建倉會重置該持倉週期的最高價與停利線。
- 日線高低價沒有盤中先後順序資訊，警示不代表成交。
- 僅供個人交易記錄及策略試算。
