# Trade Compass v1.7.4 — 投入本金／資產／收益曲線與 0050 配息路徑修正

## 修正內容

1. 在「指數型 ETF 報酬試算」原有收盤價與投資損益圖表下，新增三條同圖曲線：**累積實際成交投入本金（藍）**、**投資組合總價值（綠）**、**累積總損益（橘）**，均由既有 `compute()` 每日快照生成，與使用者的單筆買入、加碼、每月定期定額、交易日順延、0050 1 拆 4、手續費，以及所選配息模式同步。
2. 保留原始價格圖和損益圖，不修改投入紀錄的本機儲存鍵。未買入的預算不視作投入本金；股息再投入不會重複算外部投入。
3. 對 **0050、006208 配息 JSON** 先使用本站 `data/index-etf/dividends/<code>.json`，若 HTTP 404 或內容無效，再嘗試讀取 **同一公開 GitHub 儲存庫 `main` 的原始 JSON**。只採用檔案中有有效除息日、發放日、正數金額的記錄，不自動猜股息。
4. 新增官方 TWSE `etfDiv` 0050 配息資料取得／驗證工具：若有可驗證新資料就合併到 `data/index-etf/dividends/0050.json`，若來源暫時無法讀取，保留既有有效資料；若原本沒有有效資料則持續明確警示「尚未含息」。
5. 新 GitHub Actions **手動發布**流程會把 `data/index-etf/dividends/` 一起放入 GitHub Pages 網站檔案，並檢查畫面新功能已存在。同一次工作流程僅上傳一個 Pages artifact。使用者原本的三大法人、行情、ETF 資料、排程和其他 YAML 不會被覆寫。

## 安裝（GitHub 網頁版）

在 `https://github.com/tony71015-sudo/stock-tracker` 的 `main` 分支，上傳 ZIP 中以下三個檔案，**保留資料夾路徑**：

- `scripts/patch_etf_returns_v174.py`（新增）
- `scripts/refresh_0050_dividends.py`（新增）
- `.github/workflows/repair-etf-curve-dividends.yml`（新增）

`tests/` 兩個測試程式為選用，不必上傳也能執行主功能；**不需要上傳 `.pyc`**。這次請不要以舊版本的 `index_etf_returns.js` 覆蓋目前新版。新流程會針對 GitHub 上現有的 JS 做**定位式修改**；若現有檔案結構與已驗證版本不符，程式會中止並指出原因，避免刪掉近期更新。

提交之後，開啟 GitHub → Actions → **「修正ETF投入收益曲線及0050配息資料發布」** → Run workflow（新啟動，不要在舊失敗紀錄按 Re-run jobs）。該工作流程會嘗試取得 0050 官方配息、確認 JS 語法、提交修正，再進行 Pages 上傳／發布。**不要同時執行其他 Pages 部署任務**。

### 驗收

1. 打開 `https://tony71015-sudo.github.io/stock-tracker/`（Ctrl+Shift+R）。選「指數型 ETF 報酬試算」。先有一筆有效買入或每月定期定額，應看到原本兩圖及新增的三條曲線。
2. 確認橘線的最後一個值等於「總收益／總損益」欄位；藍線末值等於「投入本金累計」。請比對不同日期加碼前後的藍線階梯變化。
3. 開啟 `https://tony71015-sudo.github.io/stock-tracker/data/index-etf/dividends/0050.json`，應看到有 `etf: "0050"` 與 `events` 陣列的 JSON，**不是 404**。如仍是 404，到 GitHub `data/index-etf/dividends/0050.json` 查核資料是否真正抓到。
4. 若官方來源及 repo 都沒有 0050 的有效配息資料，選「含息總報酬」會回退為純價格報酬並提示，這是預期的資料安全機制，不代表配息問題已完全修復。
5. 若 Actions 的「Deploy GitHub Pages」因 GitHub 服務的 `github-pages` artifact 暫時無法辨識而失敗，**不要重跑失敗的同一個 run**；從 Actions 的工作流程頁面開啟新的 Run workflow。程式修改可能已成功提交，但網站尚未發布。若持續發生，應檢查 GitHub Pages 工作流程和平台狀態。

## 配息與回測限制（務必保留）

- 0050 現金配息必須來自可核對的官方或已明確來源之歷史明細；只有檔案能下載**不等於涵蓋完整上市期間**。官方資料可能缺少 2003–2004 年及其他期間。
- 若配息缺漏，不可以用 0 元代替，也不可以把「純價格報酬」寫成含息報酬。可由畫面匯入使用者自己核對的 CSV 進行補充。
- 投入本金曲線代表**按當日收盤價可成交的整股成本**（含設定手續費），與使用者輸入的預算不一定一致；未成交剩餘預算不列入本金。價格、稅負、交易成本和現金股息均有試算限制。
- 所有網站資料與試算**仍在修正與驗證中，可能有延遲、缺漏或錯誤，採用前務必核對投信、證交所與櫃買中心官方資料**。非投資建議。

## 維護與回復

- 備份 GitHub 專案或記錄修正前 commit；若需要回復，還原 `index_etf_returns.js` 上次版本即可。更新流程不移除現有投資試算資料；使用者本地 `localStorage` 紀錄不受 GitHub 檔案更新影響。
- 如果其他自動部署流程後續沒有複製 `data/index-etf/dividends/`，可能再度出現 404；請確保所有發布流程一致保存這個目錄，而不是反覆重抓相同資料。
- 資料解析與 JS 函式定位基於先前可取得的 v1.6.9 版本；無法直接確認目前 GitHub `main` 的最新來源，所以新版補丁設有嚴格匹配失敗保護。
