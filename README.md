# 投資風控中心 Trade Compass ｜整合版 v1.1

## 新增功能
- 新增「國泰損益試算」分頁，完全依提供的「國泰證券2.8折_台股損益試算表.xlsx」之 23 組漲跌幅、價格級距、手續費、稅率、報酬率公式試算。
- 支援手動輸入基準價格／股數，以及「帶入現有持股」功能，透過原交易帳本在查詢日計算股數和平均成本。
- 可設定 2.8 折或不同手續費折扣、一般現股／現股當沖稅率，以及自訂價格升降單位。
- 新增自訂賣價損益、估算損益兩平價。

1. **先到舊網站「資料匯入與備份」下載完整 JSON 備份**。
2. 登入原本的 `tony71015-sudo/stock-tracker` GitHub 專案，點選 `index.html` → 右上角編輯鉛筆圖示；可直接用新版完整內容覆蓋，或在 GitHub 網頁上使用 Add file → Upload files 上傳同名檔案以覆蓋。

5. 確認原交易還在、並測試新增國泰損益試算分頁。

## 數據與限制
- 完全靜態網站，無後端與券商 API、無即時報價、不會自動下單。
- 本機 localStorage 非跨裝置同步，請定期備份。
- Excel 的「昨日收盤價／買進成本」是一個基準價；自動套用持股模式時，平均成本已含買進手續費，**不再額外加一次買進手續費**。
- Excel 股票級距對所有 ETF 未必適用，可切換自訂升降單位；模擬買賣費用不含券商最低手續費、活動回饋或其他費用。
- 稅率選項依原 Excel：一般現股 0.3%，現股當沖 0.15%；實際適用請以法規與券商交割資料為準。
