# Trade Compass v1.5.9 版本紀錄與資料安全提醒補丁

更新日期：2026-11-15

## 檔案與放置位置
- `index.html` → 網站根目錄（取自先前 v1.5.4 版、加上新版說明；如線上有尚未備份的後續自訂修改，請先比較差異再覆蓋）

**不必替換 GitHub Actions YAML**，沿用目前已能執行的工作流程。備份原有檔案後，上傳到 `main` 並提交，再執行其他主動式 ETF 工作流程。

## 修正說明
- 原本 00994A、00408A 的日誌為 `Unrecognized TW-equity symbol: '股票'`。本版將 `股票` 與明確的股票小計／分類名稱視為摘要列而不是股票持股，不再讓它阻斷所有資料。
- 不因分類列而跳過其它個別股票、現金或期貨持股，也不把分類列加權重兩次。
- **並未保證 00994A、00408A 一定能通過所有持股完整性驗證**；須看執行後日誌，例如日期的合計權重是否合理。
- 00401A、00996A、00407A、00410A 替代來源仍依 v1.5.8 的原有流程，需透過 Actions 確認實際可用性。
- 主動 ETF 查詢頁新增資料風險提示；「版本更新與資料儲存說明」增加 v1.5.0–v1.5.9 歷程與獨立的警示區塊。

## 資料使用提醒
本站資料可能包含發行投信、第三方與開源抓取器資料，可能延遲或有缺漏，不能完全相信自動整理結果。程式檢查通過不代表已與投信官方逐筆核對。投資前請使用投信官方、臺灣證交所／櫃買中心及券商資訊交叉核對；持股變化不等同經理人實際買賣，PCF 不可直接當作完整實際持股。
